Weeklet now checks GitHub Releases when you open the popover. A compact Update button downloads a cryptographically verified release and restarts the app after installation.

- Native Ed25519 verification with a pinned publisher key.
- Pulsing green activity badges above the provider logos; multiple active chats show their count inside the badge.
- Bounded downloads, strict archive checks and an atomic app replacement.
- No backend, Apple subscription, third-party runtime package or GitHub sign-in in the app.
- Provider credentials remain strictly read-only.

This release is for Apple Silicon Macs running macOS 14 or later. It is ad-hoc signed and is not notarized by Apple; macOS may require first-launch approval. Download Weeklet-macOS-arm64.zip, extract it and move Weeklet.app to a writable Applications folder.
